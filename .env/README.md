# 🌦️ GuardiánClima ITBA (Borrador)

Aplicación de consola en Python para consultar el clima,
guardar historial global y obtener consejos de vestimenta con IA.

## Instalación

pip install -r requirements.txt

## Configuración

Crear un archivo .env con las siguientes variables:
OPENWEATHER_API_KEY=tu_key
GEMINI_API_KEY=tu_key

## Cómo correr la app

python main.py
